## 🧩 About

**StarCraft 2 Mod Menu** is a curated list of StarCraft 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, build order switcher
- **Quality-of-Life Helpers** — unit catalog, hotkey manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Build Order Switcher — practice any opening from a checkpoint
- Show Grid — visualize map grids and expansion spots
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Unit Catalog — browse units, skins, decals, portraits
- Custom Skin Notes — organize army cosmetics
- Terrain Overlay — improved map visibility

### Aimbot
- Practice Mode Notes — segment study on any build
- Camera Control — manually jump camera across the map
- Hotkey Buffer Notes — chain complex orders in the editor
